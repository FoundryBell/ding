# DING

A bell, at night. One button, one file, no build, no install.

Ring it: it grows, lowers, warms. Too much and it goes somewhere small.

**Play it:** https://foundrybell.itch.io/ding

## What this is

The radically simple opposite of a 150-component design system: 1 component.
`index.html` is the whole thing (about 11 KB). Open it in any browser.

- Art drawn in code (inline SVG): night sky, moon, hills, a house far away.
- Sound synthesized in code (Web Audio, bell partials: hum, prime, tierce, quint, nominal). No audio files, no image assets, no dependencies.
